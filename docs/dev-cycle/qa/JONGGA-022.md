`investorTrend` 는 실시간 시세 제공처가 순매수 수량에 그때그때의 종가를 곱해 만드는

출처가 다른 별개의 집계라는 항목의 진단은 그대로 유효하다. 시나리오는 이번 실측값을
따른다.

**S-3 은 1단계 리포트가 새로 찾아낸 것이다.** 이번 변경이 카드와 모달을 일치시킨 것은
최신 자료일에서만 성립하고, 날짜 선택 13개 옵션 가운데 11개에서는 여전히 어긋난다.
게다가 이번 변경이 새로 넣은 툴팁이 그 상태에서도 「카드의 「외인 (5일)」과 같은
값입니다」라고 단언한다. 이 항목이 고치기로 한 결함 그 자체이므로 범위 안이다.

## 시나리오

### S-1. 최신 자료일에서 카드와 모달의 5일 순매수가 같은 문자열이다 (회귀)
- 조작: `Latest Report` 상태에서 첫 카드(태웅 044490)의 「외인 (5일)」과 「기관 (5일)」을
  읽는다. 그 카드의 「상세 분석 보기」를 눌러 모달의 「투자자 동향 (5일 합계)」 절에서
  「외국인」과 「기관」을 읽는다. 모달을 닫고 둘째 카드(메리츠금융지주 138040)에 같은
  조작을 한다.
- 기대: 부호를 뺀 문자열이 네 쌍 모두 같다. 태웅은 카드 `23억`·`33억` 에 모달
  `+23억`·`+33억`, 메리츠금융지주는 카드 `92억`·`414억` 에 모달 `+92억`·`+414억` 이다.
  고치기 전 모달이 그리던 `52억` 과 `39억` 은 모달 전체 텍스트에서 0회다.
- 결과: 통과. 네 쌍이 모두 같다. 태웅 카드 `23억`·`33억` 에 모달 `+23억`·`+33억`,
  메리츠금융지주 카드 `92억`·`414억` 에 모달 `+92억`·`+414억` 이었다. `+52억` 과
  `+39억` 은 없다. 문자열 `52억` 이 한 번 나오지만 뉴스 제목 「이투마스 652억에
  인수」의 부분 문자열이라 수급 자리와 무관하다.

### S-2. 카드의 기관 5일 순매수가 반올림 규칙을 따른다 (회귀)
- 조작: `Latest Report` 상태에서 태웅 카드의 「기관 (5일)」을 읽는다.
- 기대: `33억` 이다. 원값이 3,276,004,650 원이므로 반올림하면 33억이고 내림하면 32억이다.
  고치기 전 카드는 내림해 `32억` 을, 모달은 반올림해 `33억` 을 적어 값이 같아도 문자열이
  갈렸다. 두 자리가 같은 함수를 쓰게 되었으므로 카드도 `33억` 이어야 한다.
- 결과: 통과. 카드가 `33억` 이다.

### S-3. 최신 자료일이 아닌 날짜에서도 두 값이 같은 값이라고 말하지 않는다 (리포트)
- 조작: 날짜 선택을 `2026-02-11` 로 바꾸고 넷째 카드(현대제철 004020)의 「외인 (5일)」과
  「기관 (5일)」을 읽는다. 그 카드의 「상세 분석 보기」를 눌러 모달의 「외국인」과 「기관」
  값을 읽고, 「외국인」 라벨 옆 물음표 아이콘의 툴팁 문구도 읽는다. 이어서 날짜를
  `2026-09-01` 로 바꾸고 둘째 카드(삼성생명 032830)에 같은 조작을 한다.
- 기대: 다음 둘 가운데 하나가 성립한다.
  **(a) 값을 맞춘 경우** — 현대제철 모달이 `+109억`·`+177억`, 삼성생명 모달이
  `+256억`·`+610억` 으로 카드와 같아진다.
  **(b) 이름으로 시점을 구분한 경우** — 값은 `-113억`·`+188억` 과 `-289억`·`+330억`
  으로 남더라도, 모달의 「외국인」 툴팁에 「카드의 「외인 (5일)」과 같은 값입니다」가
  **나오지 않고**, 그 자리에 이 값이 지금 기준의 집계임을 밝히는 문구가 있다.
  어느 쪽이든 「카드는 순매수 109억, 모달은 순매도 113억」인데 화면이 그 둘을 같은
  값이라고 말하는 상태는 남지 않는다.
- 결과: **실패 → 수정 → 통과.** (b) 안으로 고쳤다. 상세 API 는 종목코드만 받고
  날짜를 받지 않아(`app/routes/kr_market_data_backtest_stock_routes.py:54`)
  `?date=2026-02-11` 을 붙여도 같은 값을 돌려주므로 (a) 안은 백엔드 변경이
  필요해 범위를 넘는다. 값은 현대제철 `-113억`·`+188억`, 삼성생명
  `-289억`·`+330억` 으로 남았고, 대신 절 제목이 「투자자 동향 (오늘 기준
  5영업일)」로 바뀌어 시점을 늘 보이는 자리에서 밝힌다. 외국인·기관 툴팁의
  「카드의 「외인 (5일)」과 같은 값입니다」는 사라지고 「카드의 「외인 (5일)」은
  신호가 나온 거래일 기준이므로, 지난 날짜를 골랐다면 두 값이 다릅니다」가
  들어갔다. 커밋 `3feab29`.

  카드의 확정값을 쓴다는 사실도 밝힌다. 카드는 `1,085억`, 모달은 장중 누적이라 그보다

### S-8. Escape 로 모달이 닫히고 모바일 375px 에서 가로 넘침이 없다 (인접)
- 조작: 태웅 모달을 열고 Escape 를 누른다. 뷰포트를 `375x812` 로 바꿔 다시 모달을 열고

- 기대: Escape 를 누르면 모달 텍스트가 사라진다. 모바일에서 `scrollWidth` 와
