## 시나리오

### S-1. 확정 집계도 Toss 합계도 없으면 「자료 없음」을 그린다 (회귀)
- 조작: `curl` 로 `/api/kr/stock-detail/900001` 을 받아 `investorTrend`·`investorTrend5Day` 를 읽는다. 브라우저에서 QA결측 카드의 「상세 분석 보기」를 눌러 외국인·기관 칸의 글자를 읽는다.
- 기대: API 는 `investorTrend.foreign`·`institution` 이 null, `foreignDays`·`institutionDays` 가 0, `investorTrend5Day` 키 없음. 화면은 외국인·기관 모두 「자료 없음」이고 「-」나 「0」이 아니다.
- 필수 여부(required): 예
- 실제: API `investorTrend` 가 `foreign`·`institution` null, `foreignDays`·`institutionDays` 0, `investorTrend5Day` 없음. 모달 외국인 칸 「외국인자료 없음」, 기관 칸 「기관자료 없음」(칸의 textContent). 「-」·「0」 없음
- 결과: 통과
