## 검사 자료에 관한 전제

원본 `data/signals_log.csv` 는 `is_vcp` 열이 비어 있어 VCP 시그널이 0 건입니다. 이 항목이
검사하려는 것이 바로 그 빈 상태이므로, S-1~S-3·S-5~S-8 은 원본 자료를 그대로 쓰고 자료를
전혀 건드리지 않습니다.

S-4 만 「시그널이 있을 때」를 확인해야 하므로 원본 `data/` 를 심볼릭 링크로 건 사본
디렉터리를 scratchpad 에 만들고 `signals_log.csv` 한 파일만 실제 사본으로 바꾸어 그
디렉터리를 작업 디렉터리로 삼아 백엔드를 띄웁니다. `data/*` glob 은 숨은 디렉터리를
건너뛰므로 `data/.*` 도 함께 링크합니다. 검사 전후로 `git status data/` 가 비어 있음을
확인합니다.
