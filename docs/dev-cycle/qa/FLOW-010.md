  와 이번 사이클의 변경 세 파일
- 구성 2026-09-03 09:30 | 실행 (미실행)

이번 사이클은 등급 카드가 표에 그려진 현재 페이지 50행으로 통계를 다시 계산하던 것을,
백엔드가 전체 기간을 집계해 보내는 `kpi.roiByGrade` 를 읽도록 바꿨습니다. 그래서 시나리오는
「값을 다시 읽게 만드는 조작을 걸어도 등급 카드가 변하지 않는가」에 집중합니다.

## 시나리오

### S-1. 페이지를 넘겨도 등급 카드가 고정된다 (회귀)

- 조작: 화면을 연 뒤 S·A·B 카드의 건수와 승률과 평균 수익률을 읽는다. 표 아래 `Next` 를
  세 번 눌러 2·3·4페이지에서 같은 세 값을 다시 읽는다.
- 기대: 네 페이지 모두에서 S 는 `16건 / 37.5% / +0.3% / 6-10`, A 는
  `26건 / 48% / +1.6% / 12-13`, B 는 `131건 / 37.2% / +0.2% / 48-81` 이다.
  하나라도 달라지면 실패다.

- 기대: S-1 과 같은 아홉 개 값이 그대로다. 표만 7행으로 줄어든다.

- 기대: 세 카드의 값이 그대로다. 표만 1행으로 줄어든다.

- 기대: 세 카드의 값이 그대로다. 표는 173행이 되고 페이지 이동 버튼이 사라진다.

### S-5. 상단 카드와 등급 카드가 같은 숫자를 말한다 (회귀)

- 조작: 상단 「평균 수익률 (S+A+B 합산)」 카드 안의 작은 글씨를 읽는다.
- 기대: `S +0.3%` `A +1.6%` `B +0.2%` 로, 등급 카드의 평균 수익률과 자릿수까지 같다.
  백엔드는 소수 둘째 자리(`0.25`)로 보내지만 화면은 어디서나 첫째 자리로 그린다.

### S-6. 등급 필터 버튼은 현재 페이지를 센다 (인접)

- 조작: 1페이지와 2페이지에서 등급 필터 버튼의 괄호 안 숫자를 읽는다.
- 기대: 1페이지는 `S (7) A (14) B (29)`, 2페이지는 `S (3) A (4) B (43)` 이다. 바로 왼쪽
  결과 필터와 같은 기준이므로 **페이지마다 달라지는 것이 정상**이다. 이 버튼까지 전체
  기간으로 바꾸면 필터가 거를 대상과 세는 대상이 어긋난다.

## 이월한 발견

`/qa-only` 리포트가 지적했지만 이번 사이클에서 고칠 수 없어 백로그로 올린 것입니다.

- **ISSUE-001** 「누적 추천수 180 인데 표에는 173행」 → `[FLOW-013]` (P1, T3).
  백엔드가 `grade="D"` 인 거래 7건을 보내는데 화면이 S·A·B 만 그립니다. 고치려면 D 등급을
  화면에 드러낼지 집계에서 뺄지를 먼저 정해야 하고, 백엔드 집계와 화면을 함께 바꿔야
  해서 이번 범위를 넘습니다.
- **ISSUE-002** 「최근 10건 승률이 현재 페이지의 앞 10건을 본다」 → `[FLOW-012]` (P2, T2).
  이번 사이클의 `/review` 에서 이미 발견해 백로그에 올려 둔 항목이며, `/qa-only` 가
  같은 것을 다시 찾았습니다. 페이지마다 70% → 10% → 80% 로 달라지는 것을 실측했습니다.
  백엔드가 값을 보내 주지 않아 프론트엔드만으로는 고칠 수 없습니다.
- **ISSUE-003** 「평균 수익률 카드의 등급별 세부가 카드 밖으로 넘친다」 → `[FE-023]` (P2, T1).
  1280x720 에서 카드 제목이 두 줄로 접히며 생기는 레이아웃 문제입니다. 이번 사이클이
  그 세 줄의 반올림을 바꾸긴 했지만 넘침은 그 전부터 있던 배치 문제입니다.
