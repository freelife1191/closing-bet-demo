## 이 시나리오가 「저장」 버튼을 누르지 않는 이유

이번 사이클이 고친 것의 중심은 「저장」 버튼이지만, 그 버튼을 누르는 시나리오는 넣지
않았습니다. 그 버튼 하나가 프로필과 환경 변수와 관심종목을 함께 저장하고, 환경 변수 저장은
`POST /api/system/env` 로 서버의 `.env` 를 덮어씁니다. 되돌릴 수 없고 API 키가 걸려 있어
QA 가 승인 없이 실행할 자리가 아닙니다.

그래서 저장 동작 자체는 vitest 가 대신 검사합니다. `chatHelpers.test.ts` 의
`saveUserProfile` 검사 3건이 서버 POST 와 거절 시 예외와 캐시 보존을 고정하고,
`SettingsModal.save-isolation.test.tsx` 3건이 프로필 저장이 실패해도 환경 변수와
관심종목은 저장되는 것과 실패한 대상이 문구에 실리는 것을 고정합니다. 아래 시나리오는
브라우저에서 눈으로 확인할 수 있는 것만 다룹니다.

**실행할 때 지킬 제약**: 설정 모달의 「저장」 버튼을 누르지 마십시오. 모달은 「취소」 또는
「닫기」로만 닫습니다. 「알림 센터」 탭의 「테스트 발송」 세 버튼과 「API & 기능」 탭의
휴지통 버튼(`title="API Key 삭제"`)도 누르지 마십시오. 챗봇에 메시지를 보내지 마십시오.
추천 질문 카드 넷, 하단 빠른 조회 버튼 다섯, 입력창의 Enter, 슬래시 명령이 모두 실제
Gemini 호출과 쿼터 소모를 일으킵니다.

## 시나리오

### S-1. 서버가 보낸 HTML 의 헤딩이 이미 이름을 담는다 (회귀)
- 조작: `http://localhost:3500/chatbot` 의 응답 HTML 을 받아 `h1` 의 내용을 읽는다.
  브라우저 안에서라면 `fetch('/chatbot')` 의 본문을 읽는다.
- 기대: `안녕하세요, 흑기사님`. React 가 넣는 `<!-- -->` 주석을 걷어내면 이 문장이 된다.
  `안녕하세요, 님` 처럼 이름이 빠진 형태가 응답 어디에도 없다.

### S-2. 새로고침해도 헤딩이 이름 없는 문장으로 스치지 않는다 (회귀)
- 조작: `/chatbot` 을 열고 `h1` 을 읽는다. 새로고침하고 다시 읽는다. 한 번 더 새로고침해
  세 번째로 읽는다.
- 기대: 세 번 모두 `안녕하세요, 흑기사님`. 그 옆의 `h2` 는 `무엇을 도와드릴까요?` 이고
  본문 오른쪽 위 아바타는 `흑기` 다.
- 결과:

### S-3. 삭제한 함수의 이름이 콘솔에 남지 않는다 (회귀)
- 조작: 콘솔 버퍼를 비운다. `/chatbot` 을 로드하고 콘솔 오류를 읽는다. 이어서
  `/dashboard/kr` 을 로드하고 다시 읽는다.
- 기대: 두 화면 모두 오류 0건. 특히 `ReferenceError: updateUserProfile is not defined` 가
  없다. 이번 사이클이 그 함수를 지우고 `saveUserProfile` 로 대체했으므로, 참조가 남아
  있으면 여기서 걸린다.

### S-4. 설정 모달을 여는 세 경로가 모두 같은 저장 버튼을 갖는다 (회귀)
- 조작: 세 경로로 각각 모달을 열고 하단 버튼 구성과 「프로필」 절의 이름 입력창 값을
  읽은 뒤 「취소」로 닫는다.
  1. `/chatbot` 본문 오른쪽 위 원형 아바타(`흑기`)
  2. `/chatbot` 왼쪽 사이드바 아래 프로필 버튼(`U User Free Tier Plan`) → 「설정 ⌘,」
  3. `/dashboard/kr` 헤더의 「설정 열기」 버튼
- 기대: 세 경우 모두 하단에 「취소」와 「저장」 두 버튼이 있다. 이름 입력창은 1번이
  `흑기사`, 2번과 3번이 `User` 다. 이메일은 세 경우 모두 `user@example.com` 이고
  「직무 / 역할」은 `엔지니어링` 이다.
- 이 값의 어긋남 자체는 이번 항목이 고치기로 한 것이 아니다. `[FE-022]` 로 이월했고
  여기서는 세 경로가 모두 같은 저장 버튼을 갖췄다는 것만 확인한다. 종전에는 2번과 3번이
  프로필 API 를 아예 부르지 않았다.
- 결과:

### S-5. 설정 모달의 네 탭이 전환된다 (인접)

### S-6. 「취소」로 닫으면 편집한 값이 버려진다 (인접)
- 조작: `/dashboard/kr` 헤더의 「설정 열기」로 모달을 연다. 이름 입력창을 `취소검사` 로
