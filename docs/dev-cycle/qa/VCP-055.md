### S-1. Toss 빈 body 에서 스크리너가 0 대신 CSV 폴백 값을 쓴다 (하네스, 필수)
- 조작: 두 사본에서 `empty` 모드로 실행
- 기대: 수정 전은 세 종목 모두 `foreign_5d=0`·`inst_5d=0` 이다. 수정 뒤는 CSV 5일 합계에서 나온 값이거나, 폴백이 참조를 얻지 못했을 때 결측(`None`)이며 Toss 의 0 이 아니다. 수정 뒤 값은 원본 CSV 의 마지막 5거래일 합계와 대조한다

CSV 마지막 날짜가 09-21 이라 폴백이 이상징후(stale)로 pykrx·Toss 참조를 조회했으나, 소켓 차단·빈 body 로 둘 다 얻지 못해 CSV 를 썼다. 통과

### S-2. 빈 응답이 15분 캐시와 Toss 참조 캐시에 남지 않는다 (하네스, 필수)
- 조작: S-1 과 같은 실행에서 메모리 캐시 항목 수, 메모리를 비운 뒤 SQLite 스냅샷 적중 여부, `_fetch_toss_reference_trend` 결과를 기록한다
- 기대: 수정 전은 메모리 3항목·SQLite 적중 `True`·Toss 참조가 0 값 dict 다. 수정 뒤는 메모리 0항목·SQLite 적중 `False`·Toss 참조 `None` 이다
- 실제: 수정 전은 메모리 3항목, 메모리를 비운 뒤 SQLite 적중 세 종목 모두 `True`, Toss 참조 `{"foreign": 0, "institution": 0, "details": []}`. 수정 뒤는 메모리 0항목, SQLite 적중 세 종목 모두 `False`, Toss 참조 `null`. 수급 URL 요청 수는 둘 다 4회. 통과
