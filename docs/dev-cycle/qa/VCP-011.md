## 사전 조건 — 사본 환경이 필요한 이유

현재 `data/signals_log.csv` 는 `is_vcp` 열이 15행 전부 비어 있다. `_is_vcp_signal_row` 가
그 열을 보고 거르므로 `/api/kr/signals` 가 `count: 0` 을 돌려주고 VCP 표가 비어 있다.
`/api/kr/signals/dates` 도 `[]` 다. 이 상태로는 상세 패널을 열 수 없다.

`data/` 는 읽기 전용 규약이므로 원본을 고치지 않고 사본 환경을 쓴다.

    사본: <scratchpad>/vcp011-qa/data/   (json·csv·db·lock 79개를 cp 로 복사)
    사본에서만 signals_log.csv 의 is_vcp 를 True 로 바꾼다. 다른 열은 그대로 둔다.
    백엔드: gunicorn --chdir <사본> --pythonpath <저장소> flask_app:app --bind 127.0.0.1:5501

**안전 절차**: 링크를 만들지 않고 `cp` 로 실제 파일을 만든다. 편집 직전에
`os.path.islink` 로 확인하고, 편집 전후로 원본 `data/signals_log.csv` 의 SHA-256 을
대조한다. 기준 해시는
`769cab962853d377c1ee6203a661c6d37fa90d5a7cec434d7051344e34e45237` 이다.

## 범위 밖으로 두는 것

`data/ai_analysis_results_20260505.json` 에 저장된 SK 의 Gemini 사유는 지금도
「VCP 패턴 보조 점수가 3.0점 … 수축 비율 1.8811」이라고 적혀 있다. 이 글은 과거에 이미
생성되어 저장된 자료이고 `data/` 는 읽기 전용이며, 다시 만들려면 AI 를 호출해야 하는데
그것은 비용이 드는 조작이라 금지된다. **그러므로 이번 라운드가 보장하는 것은 「앞으로
만들어지는 프롬프트가 표와 같은 숫자를 싣고 없는 사실을 지어내지 않는다」와 「화면이 그
숫자를 제 이름으로 부른다」 두 가지다.** 이미 저장된 옛 사유 본문은 그대로 남는다.

## 금지 조작

`AGENTS.md` 의 「되돌릴 수 없는 조작」을 그대로 따른다. 챗봇 보내기, 입력창 Enter,
추천 질문 카드, 빠른 조회, 슬래시 명령, 삭제 확인(모달은 「취소」만), 설정 「저장」,
**재분석**, Refresh, 모의투자를 누르지 않는다. 재분석 경로는 버튼 대신 파이썬 하네스로
payload 를 만들어 확인한다.

### 같은 화면에 남은 옛 사유

상세 패널 Gemini 탭의 사유 본문은 지금도 다음과 같다. 위의 「범위 밖으로 두는 것」에 적은 대로
과거에 저장된 자료이며 이번 변경이 다시 만들지 않는다.

    VCP 패턴 보조 점수가 3.0점으로 다소 낮게 측정되었으나, 수축 비율 1.8811은 …
    당일 외국인과 기관의 순매수 규모가 0.0으로 집계되어 … 종합 시그널 점수 67점은 …

「당일 … 0.0으로 집계되어」가 바로 이번에 없앤 지어낸 0 이 실제로 AI 판정에 쓰인 증거다.
