## 시나리오

### S-1. 청산 갱신은 원자적으로 한 번 쓴다 (핵심)
- 조작: 원본에서 복사한 로그(2026-05-05 OPEN 15행)로 `update_open_signals()` 를 부른다. 보유 기간 한도를 넘었으므로 청산이 일어난다
- 기대
  - `signals_log.csv` 쓰기는 `atomic` 1회이고 `to_csv` 로 직접 쓴 것은 0회다
  - 파일이 BOM 하나로 시작하고, 행 수가 그대로이며, OPEN 이 줄고 CLOSED 가 생긴다. 임시 파일은 남지 않는다
  - 대조군은 같은 조작에서 `to_csv` 로 직접 1회 쓴다
- 필수 여부(required): 예
- 실제: 오류 없음, 쓰기 `['atomic']` 1건, 크기 1727 → 2132, BOM 시작·BOM 1개, 헤더 같음, 임시 파일 없음, `rows=15`, `{'CLOSED': 15}`. 대조군은 쓰기 `['to_csv(mode=w)']` 1건, 같은 크기와 상태
- 결과: 통과

### S-2. 쓰기 도중 실패해도 기존 로그가 잘리지 않는다
- 조작: `os.fsync` 를 실패시킨 상태에서 `update_open_signals()` 와 `_append_to_log`(당일 중복 없음, 당일 중복 있음)를 각각 부른다
- 기대: 세 경우 모두 OSError 가 호출자로 올라가고, 로그의 SHA-256 이 실행 전과 같으며, 임시 파일이 남지 않는다. 파이프라인 단계에서는 이 예외가 「SignalTracker update failed (non-critical)」 경고로 바뀐다
- 필수 여부(required): 예
- 실제: `update_open_signals`(s2upd), 당일 중복 없는 추가(s2noov), 당일 중복 병합(s2merge, QA 행을 먼저 정상 추가한 16행 1854바이트 상태에서 실행) 모두 `OSError: QA forced fsync failure`, 쓰기 시도 `atomic` 1건, 크기 그대로, `same_bytes=True`, 임시 파일 없음. 파이프라인 단계(s2pipe, `run_vcp_signals_step` 에 가짜 `create_signals_log`)는 예외 없이 끝나고 경고 「SignalTracker update failed (non-critical): QA forced fsync failure」 1건, `same_bytes=True`, 15행 OPEN 그대로. 대조군은 `to_csv` 가 fsync 를 부르지 않아 네 경우 모두 오류 없이 파일을 바꿨다(s2noov 는 `to_csv(mode=a)`). 대조군은 비원자 쓰기의 존재를 보이는 용도다
- 결과: 통과

### S-3. append 경로를 없애도 행이 같다
- 조작: 원본에서 복사한 로그에 오늘 자 QA 행(ticker `999034`, 「QA종목034」, OPEN)을 `_append_to_log` 로 추가한다
- 기대: 쓰기는 `atomic` 1회이고 `to_csv(mode="a")` 는 0회다. 기존 15행과 QA 행이 모두 남고, 열 순서가 기존 헤더를 유지하며, BOM 은 하나다. 대조군은 `mode="a"` 로 이어 쓰고 같은 행 집합을 남긴다
- 허용하는 차이(코드 리뷰 지적 1): 기존 행 전체를 다시 쓰므로 NaN 이 섞인 숫자 열의 표기가 바뀔 수 있다(예: `hold_days` 의 `3` → `3.0`). 이 현상은 종전 병합 경로와 `update_open_signals` 에서도 일어났다. 행 집합과 값은 같아야 한다
- 필수 여부(required): 예
- 실제: 새 코드는 쓰기 `['atomic']` 1건, 크기 1727 → 1854, BOM 1개, 헤더 같음, `rows=16`, QA 행 `999034`·「QA종목034」·`2026-09-23`·OPEN. 대조군은 `['to_csv(mode=a)']` 1건, 크기 1727 → 1820, 같은 16행. 두 결과를 `pd.testing.assert_frame_equal(check_dtype=False)` 로 비교해 같았고 열 순서도 같았다. 텍스트 차이 16줄은 `score` 열의 `82` → `82.0` 같은 표기뿐이다(QA 행의 77.0 이 열을 실수로 만든다)
- 결과: 통과
