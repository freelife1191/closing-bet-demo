### S-3. 상세 문구가 결측에 `원` 을 붙이지 않는다 (필수, 브라우저)
- 조작: SK 행과 삼성전자 행을 차례로 눌러 상세 패널을 연다
- 기대: SK 는 「외국인 5일 순매수 - · 기관 5일 순매수 0원」, 삼성전자는 두 값 모두 금액 뒤에 「원」이 붙는다. 수정 전 사본은 SK 에서 「0원」 두 개를 표시한다
