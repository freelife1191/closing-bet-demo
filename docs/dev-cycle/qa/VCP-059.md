### S-2. 가격 동기화 → 오늘 판정 병합 → 가격 동기화 순서에서 날짜 없는 파일은 병합 때만 바뀐다 (하네스, 필수)
- 조작: S-1 과 같은 자료에서 가격 동기화, 오늘 날짜 파일이 있는 상태로 000660 SELL 판정 병합, 다시 가격 동기화를 부른다
- 기대: 수정 뒤 AI 파일의 가격 이력이 [(100, 0.0)·(200, 0.0)] ×2 → [(100, 0.0)·(None, None)] ×2 이고(3번은 병합이 쓴 날짜 파일의 값이며, 000660 은 날짜 파일에 없던 종목이라 가격 키가 없다), 마지막 동기화 전후 바이트가 같다. 판정은 005930 BUY·000660 SELL, 로그 가격 005930 (110, 10.0)·000660 (220, 10.0). 수정 전은 (100, 0.0)·(200, 0.0) → (110, 10.0)·(220, 10.0) → (100, 0.0)·(None, None) → (110, 10.0)·(220, 0.0) 으로 오간다(결함 재현. 마지막 000660 의 0.0 은 `entry_price` 가 없어 현재가를 진입가로 쓴 값이다)
