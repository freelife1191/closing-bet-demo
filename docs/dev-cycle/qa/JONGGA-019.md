## 실행하기 전에 읽을 것

**실제 자료로는 이 사이클이 고친 경로에 닿을 수 없습니다.** 1단계에서 최신 자료일 3종목
(한화생명 088350, LG에너지솔루션 373220, 삼성중공업 010140)과 `2026-02-11` 4종목
(LG전자 066570, 아크릴 0007C0, 메리츠금융지주 138040, 현대제철 004020)을 모두 확인했는데
일곱 종목이 전부 상세 API 에서 정상 시세를 받습니다. 화면을 누르는 것만으로는 값 없음
분기가 나오지 않습니다.

그래서 S-1 부터 S-3 까지는 **상세 API 의 응답을 가로채서** 백엔드가 실제로 낼 수 있는
응답을 재현합니다. 가로채는 값은 지어낸 것이 아니라 실측한 것입니다. 없는 종목코드로
`/api/kr/stock-detail/999999` 를 부르면 아래 S-1 의 payload 가 그대로 옵니다.

가로채기는 `gstack browse` 가 지원하지 않으므로 `agent-browser` 를 씁니다. 세션 이름은
`adguard-cft-extension` 을 그대로 씁니다.

    export AGENT_BROWSER_SESSION="adguard-cft-extension"
    agent-browser network route "**/api/kr/stock-detail/**" --body '<payload>'
    # ... 검사 ...
    agent-browser network unroute

**시나리오를 마치면 반드시 `network unroute` 로 되돌립니다.** 되돌리지 않으면 뒤의
시나리오가 가로챈 응답을 계속 받습니다.

**누르지 말아야 할 버튼이 둘 있습니다.** DATA STATUS 절의 스크리너 전체 업데이트 버튼
(`fa-sync-alt`)과 GEMINI AI 재호출 버튼(`fa-brain`)입니다. 두 버튼은 LLM API 호출을
일으켜 실제 비용이 듭니다. 날짜 선택 오른쪽의 재조회 버튼은 비용이 들지 않습니다.

### S-4. 시세를 받은 종목은 종전대로 막대를 그린다 (인접)

- 조작: `network unroute` 로 가로채기를 되돌린 뒤 화면을 새로 고치고 첫 카드
  (한화생명 088350)의 「상세 분석 보기」를 누른다.
- 기대: 안내 문구가 **0건**이다. 「1일 범위」는 `L: ₩5,790` / `H: ₩6,550`, 「52주 범위」는
  `L: ₩2,930` / `H: ₩7,560` 이고 두 자리 모두 현재가가 `₩6,110` 으로 적힌다. 손잡이는
  각각 `42.1%` 와 `68.7%` 자리에 놓인다.
  (시세는 장중에 움직이므로 값이 달라질 수 있다. 그때는 `L < 현재가 < H` 가 성립하고
  손잡이 비율이 `(현재가 - L) / (H - L)` 과 맞는지로 판정한다. 값 없음일 때 놓이던
  `50%` 와 구분되는 것이 요점이다.)
