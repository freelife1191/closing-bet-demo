## 시나리오

### S-1. 스캔이 저장한 오늘 행은 모두 is_vcp 가 참이다 (핵심)
- 조작: 원본에서 복사한 자료로 `scan_today_signals()` 를 부른다
- 기대
  - 반환 행이 1개 이상이고, 로그의 오늘 자 행은 반환 행과 개수가 같으며 `is_vcp` 가 모두 참이다
  - 기존 행(2026-05-05)의 `is_vcp` 는 비어 있는 그대로다
  - 대조군은 오늘 자 행의 `is_vcp` 가 비어 있다
- 필수 여부(required): 예
- 실제: 반환 49행, 로그 64행(기존 15 + 오늘 49), 오늘 자 49행의 `is_vcp` 모두 1.0(참), 기존 행은 `nan` 그대로. 종목 예: 000370 한화손해보험, 001510 SK증권, 009150 삼성전기. 대조군은 같은 49행이 저장되고 `is_vcp` 는 모두 `nan`
- 결과: 통과

### S-2. 메뉴 2 의 저장 단계를 거쳐도 is_vcp 가 남는다
- 조작: S-1 의 반환 프레임에 `ai_action`·`ai_confidence`·`ai_reason` 열을 붙여 `_append_to_log` 로 다시 저장한다(당일 중복 병합 경로)
- 기대: 오늘 자 행의 개수는 S-1 과 같고(중복 없음), `is_vcp` 는 모두 참이며, AI 열이 채워져 있다
- 필수 여부(required): 예
- 실제: 로그 64행 그대로, 오늘 자 49행(중복 없음), `is_vcp` 모두 `True`, `ai_action=HOLD`·`ai_confidence=50.0`·`ai_reason` 채워짐, 기존 행 `nan` 그대로. 대조군은 AI 열은 채워지고 `is_vcp` 는 `nan`
- 결과: 통과

### S-3. 화면과 API 에 스캔한 시그널이 보인다
