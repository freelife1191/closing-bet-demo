## 알려진 한계 (판정과 무관)

- 「진도 어때」·「노을 어때」·「한창 전망」 처럼 이름 자체가 일반 명사이고 앞말이 없는 질문은 여전히 문맥이 실린다(승인된 대가, 코드의 `ponytail:` 주석).
