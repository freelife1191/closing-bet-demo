# [FLOW-013] SQLite 캐시에서 되살린 수급 항목의 5일치 불변식 — QA 시나리오

- 대상 화면: http://localhost:3500/dashboard/kr/closing-bet
- 대상 API: http://localhost:5501/api/kr/stock-detail/<종목코드>
- 구성 근거: `/qa-only` 리포트
  (`.gstack/qa-reports/qa-report-localhost-3500-2026-09-05-flow013.md`)
  + 이번 사이클의 변경 두 파일 (`services/investor_trend_5day_service.py`,
  `tests/services/test_investor_trend_5day_service.py`)
- 구성 2026-09-05 10:05 | 실행 2026-09-05 10:28

## 이번 변경이 화면에 닿는 경로

`_deserialize_trend_map` 은 SQLite 스냅숏을 되살리는 함수다. 이번 변경 전에는 되살릴 수
없는 행을 `continue` 로 건너뛰고 남은 행에 `days: 5` 를 무조건 붙였다. 그래서 네 거래일치
`details` 만 든 항목이 다섯인 척 나갔고, `_detect_csv_anomaly_flags` 가
`insufficient_days` 를 붙여 불필요한 참조 조회를 부르며 `_score_supply_core` 의 연속 부호
스트릭이 하루를 잃었다. 이번 변경은 그런 캐시를 통째로 버리고 CSV 에서 다시 만들게 한다.

그 결과가 `services/kr_market_stock_detail_service.py:232` 를 거쳐 종목 상세 API 의
`investorTrend5Day` 로 실리고, 종가베팅 카드의 상세 모달에 「투자자 동향 (오늘 기준
5영업일)」로 그려진다.

**이번 변경은 화면에 새로운 값을 그리지 않는다.** 오늘의 캐시가 온전하므로 정상 경로에서
값이 달라지지 않는 것이 옳은 동작이다. 그래서 시나리오의 절반은 「값이 그대로인가」를
확인하는 회귀 검사이고, 손상 처리 자체는 회귀 테스트와 아래 「구성 단계의 실측」이 맡는다.

**카드의 「외인 (5일)」은 검사 대상이 아니다.** 그 값은 시그널 파일이 신호가 나온 거래일
기준으로 저장해 둔 것이라 수급 서비스를 거치지 않는다. 두 값이 갈리는 것 자체는 S-6 에서
의도된 동작으로 확인한다.

## 구성 단계의 실측

시나리오를 쓰기 전에 실제 캐시로 이번 변경의 핵심 동작을 확인했다. `/qa` 가 이 조작을
반복하지는 않는다. 캐시 DB 를 손상시키는 조작이라 자동 실행에 맡길 것이 아니기 때문이다.
아래는 그 실측 결과이며, 시나리오 S-1 이 같은 성질을 회귀 테스트로 검사한다.

`data/runtime_cache.db` 를 백업한 뒤 `investor_trend_5day_unified::latest` 스냅숏에서
로보티즈(108490)의 `details` 를 다섯에서 네 건으로 줄이고, 메모리 캐시를 비우려 Flask 를
재기동한 다음 수급 서비스를 직접 호출했다.

    WARNING services.investor_trend_5day_service:
      Discarding trend snapshot: 108490 has 4 days, expected 5
    결과 foreign = 84286017500
    결과 institution = 35863006000
    결과 days = 5

손상을 발견해 경고를 남기고 스냅숏을 버린 뒤 CSV 에서 다시 만들어 정확한 값을 돌려주었다.
이어서 캐시 DB 를 다시 읽으니 같은 키의 스냅숏이 `2026-09-05T09:48:39` 로 갱신되어 있었고
2002 종목 전부 `details` 가 다섯 건이었다. 손상 스냅숏이 제자리에서 교체되므로 무한 캐시
미스가 생기지 않는다.

종목 상세 API 로는 이 동작을 관찰할 수 없다. 그 경로는 `data/.kr_stock_detail_cache/` 에
종목별 응답 스냅숏을 따로 두고 있어서 수급 조회 자체가 매 요청마다 일어나지는 않는다.

## 시나리오

### S-1. 손상된 캐시를 버리는 회귀 검사가 통과한다 (회귀)
- 조작: `source venv/bin/activate && pytest tests/services/test_investor_trend_5day_service.py -k deserialize -v`
- 기대: 네 건이 모두 PASS 한다. `test_deserialize_rejects_a_row_whose_details_are_short`
  (네 거래일치 항목을 버린다), `test_deserialize_keeps_a_row_with_five_days`
  (다섯 건짜리는 그대로 되살린다), `test_deserialize_rejects_a_malformed_row_instead_of_dropping_it`
  (손상된 행 하나가 있으면 남은 행까지 버린다),
  `test_deserialize_rejects_infinity_from_a_corrupted_snapshot`
  (`json.loads` 가 만든 `float("inf")` 에 `OverflowError` 가 나가지 않는다) 네 건이다.
- 결과: 통과. 네 건 모두 PASSED (`4 passed, 32 deselected in 0.33s`).

### S-2. 파일 전체 검사가 통과한다 (회귀)
- 조작: `source venv/bin/activate && pytest tests/services/test_investor_trend_5day_service.py`
- 기대: 36건이 모두 PASS 한다. 기존 검사 가운데
  `test_investor_trend_5day_service_reuses_sqlite_snapshot_after_memory_clear` 가 정상
  스냅숏의 재사용을 확인하므로, 이번 변경이 온전한 캐시까지 버리지는 않는다는 것이 이
  검사로 함께 확인된다.
- 결과: 통과. `36 passed in 2.73s`.

### S-4. 화면 모달의 값이 API 값과 같다 (회귀)
- 조작: 화면을 열고 카드 아홉 장의 「상세 분석 보기」를 차례로 눌러 각 모달의

- 기대: 억 단위로 반올림한 아래 아홉 쌍과 일치하며, S-3 의 원값과 같은 값이다.

- 결과: 통과. 아홉 종목의 모달 값이 억 단위 기대값과 모두 일치했다 (9/9).

### S-5. 종목을 바꾸면 수급 값도 함께 바뀐다 (인접)
- 조작: 로보티즈 모달을 열어 값을 읽고 닫은 뒤, SK이노베이션 모달을 열어 값을 읽는다.
- 기대: 로보티즈는 `+843억 / +359억`, SK이노베이션은 `+826억 / +1625억` 로 서로 다르다.
  한 종목의 값이 캐시되어 다른 종목에 재사용되지 않는다. 이번 변경이 캐시 채택 여부를
  건드렸으므로 종목 사이의 값 섞임이 없는지 확인한다.
- 결과: 통과. 로보티즈 `+843억 / +359억`, SK이노베이션 `+826억 / +1625억` 로 서로 달랐다.

### S-6. 카드와 모달이 서로 다른 기준일을 쓴다 (인접)
- 조작: 날짜 선택 상자를 2026-09-04 이전의 `2026-02-11` 로 바꾼 뒤 LG전자(066570) 카드의
  「외인 (5일)」을 읽고, 같은 카드의 상세 모달을 열어 「투자자 동향」의 외국인과 기관을
  읽는다.
- 기대: 카드는 `689억` 이고 모달은 `-249억 / -51억` 이다. 카드는 신호가 나온 거래일
  기준이고 모달은 늘 오늘 기준이므로 두 값이 다른 것이 정상이다. 과거 날짜는 캐시 키의
  `target_token` 이 달라지는 경로이므로 이번 변경이 그 경로도 깨뜨리지 않았는지 본다.
- 결과: 통과. 카드 `689억 / 326억`, 모달 `-249억 / -51억` 로 기대값과 같았다.

### S-7. 등급 필터를 걸어도 모달의 수급 값이 같다 (인접)
- 조작: 등급 필터를 「A급 이상」으로 바꾸고 남은 카드의 상세 모달을 연다. 이어서
  「S급 이상」으로 바꾸고, 마지막으로 「전체」로 되돌린다.
- 기대: 「A급 이상」에서 카드가 1건(로보티즈)으로 줄고 그 종목의 모달 수급 값은 필터를
  걸기 전과 같은 `+843억 / +359억` 이다. 「S급 이상」은 0건이고 `No Signals Found` 가
  나온다. 오늘 시그널 아홉 건의 등급이 A 1건과 B 8건이고 S 가 없기 때문이다. 「전체」로
  되돌리면 9건이 복구된다.
- 결과: 통과. 「A급 이상」 1건에 모달 값 `+843억 / +359억`, 「S급 이상」 0건과 `No Signals Found`, 「전체」 9건 복구.

### S-8. 모달을 닫는 두 수단이 모두 동작하고 좁은 화면에서도 값이 온전하다 (인접)
- 조작: 로보티즈 모달을 열어 닫기 버튼(`aria-label="닫기"`)으로 닫고, 다시 열어 Escape
  키로 닫는다. 그다음 뷰포트를 375x812 로 바꾸고 같은 모달을 연다.
- 기대: 두 수단 모두 모달을 없앤다. 375 폭에서 `scrollWidth` 와 `clientWidth` 가 모두
  375 로 가로 넘침이 없고, 외국인·기관·개인 세 값이 데스크톱과 같은
  `+843억 / +359억 / -1526억` 로 읽힌다. 콘솔에 오류가 남지 않는다.
- 결과: 통과. 닫기 버튼과 Escape 모두 모달을 없앴고, 375 폭에서 `scrollWidth` 와 `clientWidth` 가 모두 375 로 가로 넘침이 없었으며 세 값이 `+843억 / +359억 / -1526억` 로 데스크톱과 같았다. 콘솔 오류 0건.
