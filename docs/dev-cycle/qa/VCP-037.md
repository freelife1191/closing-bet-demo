## 시나리오

### S-1. 스캔만 하면 로그가 바뀌지 않는다 (핵심, 저장 질문에 N)
- 조작: 원본에서 복사한 자료로 `scan_today_signals()` 를 부른다
- 기대
  - 반환 행이 1개 이상이고 모두 `is_vcp` 가 참이다
  - `signals_log.csv` 의 바이트가 스캔 전과 같다(오늘 자 행 0)
  - 대조군은 같은 스캔으로 오늘 자 행이 저장된다
- 필수 여부(required): 예
- 실제: 반환 49행, 반환 `is_vcp` 모두 True, 스캔 전후 로그 sha256 동일(`log_unchanged=True`), 로그 15행 그대로·오늘 자 0행. 대조군은 `log_unchanged=False`, 로그 64행(오늘 자 49행, `is_vcp` 1.0, AI 열 `nan`)
- 결과: 통과

### S-2. 저장 단계를 거치면 AI 열과 is_vcp 가 함께 기록된다 (저장 질문에 y)
- 조작: S-1 의 반환 프레임에 `ai_action`·`ai_confidence`·`ai_reason` 열을 붙여 `_append_to_log` 로 저장한다
- 기대: 오늘 자 행의 개수가 반환 행과 같고, `is_vcp` 는 모두 참이며, AI 열이 채워져 있다. 기존 행은 그대로다
- 필수 여부(required): 예
- 실제: 로그 64행(기존 15 + 오늘 49), 오늘 자 49행 `is_vcp` 모두 1.0, `ai_action=HOLD`·`ai_confidence=50.0`·`ai_reason` 채워짐, 기존 행 `is_vcp` 는 `nan` 그대로. 종목 예: 000370 한화손해보험, 009150 삼성전기
- 결과: 통과

### S-3. 화면과 API 는 저장한 경우에만 스캔한 시그널을 보인다
- 조작: S-1 상태(스캔만 한 로그)와 S-2 상태(저장한 로그)로 각각 격리 서버의 API 를 읽고 `/dashboard/kr/vcp` 를 연다
- 기대
  - S-1 상태에서는 `GET /api/kr/signals/dates` 에 오늘 날짜가 없고 화면 표에 오늘 자 행이 없다
  - S-2 상태에서는 오늘 날짜가 있고, 날짜 없는 `GET /api/kr/signals` 가 200, `source=signals_log.csv` 이며 AI 추천이 붙은 S-1 종목을 돌려준다. 화면에 그 종목이 보인다
  - 콘솔 오류와 5xx 는 0 이다
- 필수 여부(required): 예
- 실제: S-1 상태에서 `dates` → `[]`, 날짜 없는 조회 → `source=no_data`·0건, 화면 표 0행과 「오늘(2026-09-23) 기준 VCP 시그널이 없습니다」 문구. S-2 상태에서 `dates` → `["2026-09-23"]`, 조회 → `source=signals_log.csv`·`count=20`(LS ELECTRIC 010120, 삼성전기 009150, 인바디 041830 …), 각 행 `gemini_recommendation.action=HOLD`. 화면 표 20행에 「LS ELECTRIC」·「삼성전기」 있음(스크린샷 `vcp037-s3-state2.png`). `console --errors` 두 번 모두 「no console errors」. access 로그 25건 모두 200, error 로그의 Traceback·ERROR 0건
- 결과: 통과
