## 시나리오

### S-1. 스캔만 하면 로그가 바뀌지 않는다 (핵심, 저장 질문에 N)
- 조작: 원본에서 복사한 자료로 `scan_today_signals()` 를 부른다
- 기대
  - 반환 행이 1개 이상이고 모두 `is_vcp` 가 참이다
  - `signals_log.csv` 의 바이트가 스캔 전과 같다(오늘 자 행 0)
  - 대조군은 같은 스캔으로 오늘 자 행이 저장된다
- 필수 여부(required): 예

### S-2. 저장 단계를 거치면 AI 열과 is_vcp 가 함께 기록된다 (저장 질문에 y)
- 조작: S-1 의 반환 프레임에 `ai_action`·`ai_confidence`·`ai_reason` 열을 붙여 `_append_to_log` 로 저장한다
- 기대: 오늘 자 행의 개수가 반환 행과 같고, `is_vcp` 는 모두 참이며, AI 열이 채워져 있다. 기존 행은 그대로다
- 필수 여부(required): 예

### S-3. 화면과 API 는 저장한 경우에만 스캔한 시그널을 보인다
- 조작: S-1 상태(스캔만 한 로그)와 S-2 상태(저장한 로그)로 각각 격리 서버의 API 를 읽고 `/dashboard/kr/vcp` 를 연다
- 기대
  - S-1 상태에서는 `GET /api/kr/signals/dates` 에 오늘 날짜가 없고 화면 표에 오늘 자 행이 없다
  - S-2 상태에서는 오늘 날짜가 있고, 날짜 없는 `GET /api/kr/signals` 가 200, `source=signals_log.csv` 이며 AI 추천이 붙은 S-1 종목을 돌려준다. 화면에 그 종목이 보인다
  - 콘솔 오류와 5xx 는 0 이다
- 필수 여부(required): 예
