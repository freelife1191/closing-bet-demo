## 시나리오

### S-1. 「크게 보기」 차트가 그 카드의 종목을 그린다 (회귀)
- 조작: `Latest Report` 상태에서 첫 카드(태웅)의 미니차트를 누른다. 미니차트는 카드 왼쪽
  아래 높이 96px 짜리 영역이며 hover 하면 「크게 보기」 라벨이 뜬다. 모달 안 `img` 의
  `src` 와 `alt` 와 `naturalWidth`×`naturalHeight` 를 읽는다. 모달을 닫고 둘째
  카드(메리츠금융지주)에 같은 조작을 한다.
- 기대: 태웅은 `src` 가
  `https://ssl.pstatic.net/imgfinance/chart/item/candle/day/044490.png`,
  `alt` 가 `태웅 044490 일봉 차트`, 자연 크기가 `700x289` 이고 `complete` 가 참이다.
  메리츠금융지주는 `.../candle/day/138040.png`, `메리츠금융지주 138040 일봉 차트`,
  `700x289` 다. 모달 제목도 각각 `태웅 044490`, `메리츠금융지주 138040` 이다.
- 결과: 통과. 태웅은 `.../candle/day/044490.png` `태웅 044490 일봉 차트` `700x289`
  `complete=true`, 메리츠금융지주는 `.../candle/day/138040.png`
  `메리츠금융지주 138040 일봉 차트` `700x289` 다. 모달 머리글이 종목명과 종목코드를
  나란히 그려 각각 `태웅 044490`, `메리츠금융지주 138040` 을 보여준다.

### S-2. 영문자가 든 종목코드도 그 종목을 그린다 (회귀)
- 조작: 날짜 선택을 `2026-02-11` 로 바꾸고 둘째 카드(아크릴)의 미니차트를 누른다.
- 기대: `src` 가 `.../candle/day/0007C0.png`, `alt` 가 `아크릴 0007C0 일봉 차트`,
  자연 크기가 `700x289` 다. 코드를 여섯 자리 숫자로 좁혀 떨어뜨리지 않는다.
- 결과: 통과. `.../candle/day/0007C0.png` `아크릴 0007C0 일봉 차트` `700x289`
  `complete=true` 다. 여섯 자리 숫자로 좁히지 않아 영문자가 든 코드도 살아 있다.

### S-3. 차트를 못 불러오면 그 사실을 알리고 다른 종목으로 대체하지 않는다 (회귀)
- 조작: `2026-02-11` 상태에서 브라우저를 오프라인으로 만든다
  (`browse cdp Network.emulateNetworkConditions '{"offline":true,"latency":0,
  "downloadThroughput":0,"uploadThroughput":0}'`). 그 상태에서 넷째 카드(현대제철)의
  미니차트를 눌러 모달을 연다. 확인이 끝나면 `"offline":false` 로 되돌린다.
- 기대: 모달에 `현대제철 (004020) 차트를 불러오지 못했습니다` 와 `다른 종목의 차트를
  대신 보여주지 않습니다. 아래 네이버 금융이나 토스 증권에서 확인하세요.` 가 나오고,
  `img[src*=pstatic]` 이 DOM 에 하나도 없다. 다른 종목의 차트가 대신 그려지지 않는다.
  온라인으로 되돌린 뒤 「일봉」 버튼을 다시 누르면 `.../candle/day/004020.png` 가
  `700x289` 로 로드되고 실패 문구가 사라진다.
- 결과: 통과. 오프라인에서 `현대제철 (004020) 차트를 불러오지 못했습니다` 와
  `다른 종목의 차트를 대신 보여주지 않습니다. 아래 네이버 금융이나 토스 증권에서
  확인하세요.` 가 나오고 `img[src*=pstatic]` 이 0개다. 온라인으로 되돌려 「일봉」을
  다시 누르자 `.../candle/day/004020.png` 가 `700x289` 로 로드되고 실패 문구가
  사라졌다.

### S-4. TradingView 임베드가 문서에서 사라졌다 (회귀)
- 조작: 차트 모달이 열린 상태에서 문서의 `iframe` 개수와, `src` 에 `tradingview` 가 든
  `script` 개수를 센다.
- 기대: 둘 다 0 이다. 교차 출처 iframe 이 없으므로 앱이 감지하지 못하는 조용한 대체가
  일어날 자리 자체가 없다.
- 결과: 통과. `iframe` 0개, `src` 에 `tradingview` 가 든 `script` 0개다. 문서 전체
  HTML 에서 `tradingview` 문자열이 0회로 흔적이 남지 않았다.

### S-5. 기간 버튼이 그 기간의 차트로 바꾼다 (인접)
- 조작: 태웅 차트 모달에서 「주봉」을 누르고 `src` 와 자연 크기를 읽는다. 이어서 「월봉」에
  같은 조작을 한다.
- 기대: 주봉은 `.../candle/week/044490.png`, 월봉은 `.../candle/month/044490.png` 이며
  둘 다 `700x289` 로 로드된다. 종목코드는 `044490` 그대로다.
- 결과: 통과. 주봉은 `.../candle/week/044490.png` `태웅 044490 주봉 차트`, 월봉은
  `.../candle/month/044490.png` `태웅 044490 월봉 차트` 이며 둘 다 `700x289` 로
  로드된다. 종목코드가 `044490` 그대로다.

### S-6. 모달 아래 두 링크가 그 종목을 가리키고 짧은 창에서도 닿는다 (인접)
- 조작: 태웅 차트 모달에서 두 링크의 `href` 를 읽는다. 그다음 뷰포트를 `1280x500` 으로
  줄여 링크의 화면 안 위치를 확인하고, 모달 안쪽을 끝까지 스크롤한 뒤 다시 확인한다.
- 기대: `href` 가 `https://m.stock.naver.com/domestic/stock/044490/chart` 와
  `https://tossinvest.com/stocks/044490` 이고 둘 다 `target="_blank"`
  `rel="noopener noreferrer"` 다. 세로 500px 에서는 처음에 링크가 화면 밖(`top` 약 509,
  창 높이 500)이지만 모달 안쪽이 스크롤되므로(`scrollHeight` 444 > `clientHeight` 351)
  끝까지 내리면 두 링크 모두 화면 안(`top` 약 416)으로 들어온다.
- 결과: 통과. `href` 가 `https://m.stock.naver.com/domestic/stock/044490/chart` 와
  `https://tossinvest.com/stocks/044490` 이고 둘 다 `target="_blank"`
  `rel="noopener noreferrer"` 다. 세로 500px 에서 `scrollHeight` 444 >
  `clientHeight` 351 이며, 처음에는 링크가 `top=509` 로 창(500) 밖이지만
  모달 안쪽을 끝까지 내리면(`scrollTop=93`) `top=416` 으로 들어온다.

### S-7. Escape 와 배경 클릭으로 모달이 닫힌다 (인접)
- 조작: 차트 모달을 열고 Escape 를 누른다. 다시 열고 이번에는 모달 바깥의 어두운 배경을
  누른다.
- 기대: 두 경우 모두 모달이 사라지고 `img[src*=pstatic]` 이 0개가 된다.
- 결과: 통과. Escape 를 누르자 `img[src*=pstatic]` 이 0개가 되었고, 다시 연 뒤
  어두운 배경을 누르자 역시 0개가 되었다. 다만 배경이 화면 상단 32px 을 덮지 않는
  것을 함께 확인했다. 이번 변경과 무관한 기존 현상이라 「시나리오 밖 발견」에 적었다.

### S-8. 날짜를 왕복해도 차트가 그 카드의 종목을 따른다 (인접)
- 조작: `2026-02-11` 로 바꿨다가 `Latest Report` 로 되돌린 뒤 첫 카드의 미니차트를 연다.
- 기대: `2026-02-11` 에서는 카드 4장(LG전자·아크릴·메리츠금융지주·현대제철)이고,
  `Latest Report` 로 되돌리면 카드 2장(태웅·메리츠금융지주)이다. 되돌린 뒤 첫 카드의
  차트는 다시 `.../candle/day/044490.png` 이며 앞 날짜의 종목이 남아 있지 않다.
- 결과: 통과. `2026-02-11` 에서 카드 4장(LG전자·아크릴·메리츠금융지주·현대제철),
  `Latest Report` 로 되돌리면 2장(태웅·메리츠금융지주)이다. 되돌린 뒤 첫 카드의
  차트는 `.../candle/day/044490.png` 이고 문서의 차트 이미지가 1개뿐이라 앞 날짜의
  종목이 남지 않았다.

### S-9. 모바일 375px 에서 가로 넘침이 없다 (인접)
- 조작: 뷰포트를 `375x812` 로 바꾸고 차트 모달을 연다. 문서의 `scrollWidth` 와
  `clientWidth`, 모달과 이미지의 크기를 읽는다.
- 기대: `scrollWidth` 와 `clientWidth` 가 모두 375 로 가로 넘침이 0 이다. 모달은
  약 343×357, 이미지는 약 309×128 로 창 안에 들어간다. 기간 버튼 세 개는 각각 45px
  폭이다.
- 결과: 통과. `scrollWidth` 와 `clientWidth` 가 모두 375 로 가로 넘침이 0 이다.
  모달은 343×357, 이미지는 309×128, 기간 버튼은 세 개 모두 45px 폭이다.

### S-10. 조작 전후로 콘솔 오류가 없다 (인접)

- 기대: 앱이 낸 오류가 0건이다. S-3 의 오프라인 조작이 남긴
  `net::ERR_INTERNET_DISCONNECTED` 는 검사자가 만든 것이므로 세지 않는다.
- 결과: 통과. 앱이 낸 오류가 0건이다. 남은 `net::ERR_INTERNET_DISCONNECTED` 두 건은
  S-3 의 오프라인 조작과 1단계 `/qa-only` 의 같은 조작이 낸 것이므로 세지 않았다.
