## 검사 대상에 관한 전제

종전 `run_screening` 은 `is_vcp` 와 `score ≥ 60` 을 함께 요구했고, 합산(수급 ≤70 + 거래량 ≤20 + VCP ≤10) 구성에서 패턴
통과 종목이 60 을 넘는 일이 40거래일 동안 없었다. 이제 저장 조건은 `is_vcp` 뿐이고 점수는 정렬과 상위 20 제한, 등급 산정에만
쓴다. 화면 판정 `_is_vcp_signal_row` 도 점수 조건을 뺐고, 날짜 목록 라우트는 `score` 열을 읽지 않는다. 고치기 전의 같은 자료
재현은 0건이었다(등록 근거).
