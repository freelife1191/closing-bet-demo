## 검사 대상에 관한 전제

이번 변경은 legacy 분석 파일로 오늘 분석의 빈 자리를 채우는 함수 하나를 바꿉니다. 세
프로바이더 필드를 한 상수로 묶어 대칭을 맞추었고, `gpt_recommendation` 이 그 목록에서
빠져 있던 것이 이 항목의 결함입니다.

현재 `data/` 의 `ai_analysis_results_20260505.json` 과 `kr_ai_analysis.json` 은 내용이
같습니다. 두 파일을 같은 실행이 함께 쓰기 때문입니다. 두 파일이 같으면 보강할 빈 자리가
없으므로 결함도 수정도 드러나지 않습니다.

그래서 원본 `data/` 를 심볼릭 링크로 건 사본 디렉터리를 scratchpad 에 만들고 세 파일만
실제 사본으로 바꾸어, 그 디렉터리를 작업 디렉터리로 삼아 백엔드를 다시 띄웁니다. 바꾼
내용과 이유는 `/qa-only` 리포트의 「검사 자료에 관한 전제」 절에 표로 있습니다. 쓰기가
일어나는 SQLite 캐시는 링크를 지워 사본 디렉터리에 새로 만들어지게 합니다. 코드에는 손대지
않고 원본 `data/` 는 읽기만 하며, 실행이 끝나면 사본과 임시 프로세스를 지웁니다.

「고치기 전」 값은 `git worktree` 로 `ccd15d5` 를 별도 디렉터리에 체크아웃하고 그 코드로
백엔드를 띄워 읽습니다. `PYTHONPATH` 만 바꾸는 방법은 gunicorn 에서 적용되지 않아 원본
코드가 그대로 적재되므로, worktree 디렉터리 자체를 작업 디렉터리로 삼고 자료 디렉터리를
사본에 연결합니다. 그 코드가 실제로 적재되었는지는 임시 표식 로그로 확인합니다.

### S-3. 종목 상세 모달의 GPT 탭이 살아난다 (회귀)
- 조작: 표에서 SK(034730) 종목명을 눌러 상세 모달을 열고 AI 탭 구성을 읽는다.

  legacy 사유를 보인다. 고치기 전에는 탭이 「Gemini」 하나뿐이다. 화면의 `getAIBadge` 는
  `aiData` 로 폴백하지만 이 자료에서 `/api/kr/ai-analysis` 는
  `jongga_v2_integrated_history` 갈래를 타고 VCP 종목을 하나도 담지 않으므로, 백엔드
  보강이 유일한 GPT 출처다.
- 필수 여부(required): 예
- 실제: 「GPT」와 「Gemini」 두 탭이 나왔고 GPT 탭 본문이

  본문에는 그 표식이 없었다. `ccd15d5` 코드로는 탭이 「Gemini」 하나뿐이었다.
  `/api/kr/ai-analysis` 응답은 `source: jongga_v2_integrated_history` 이고 시그널 아홉
  건이 모두 종가베팅 종목이라 VCP 네 종목을 담지 않았으므로, 화면의 `aiData` 폴백이

### S-4. 오늘 판정이 legacy 판정에 밀려나지 않는다 (회귀)
- 조작: legacy 사본의 `gemini_recommendation` 을 `SELL` 로 바꾸고 사유 앞에
  `[legacy 판정]` 을 붙인 상태로 S-1 과 S-2 를 다시 확인한다. 이어서 오늘 분석 파일의
  `gemini_recommendation` 을 실패 기록(`action` 이 `N/A`, `reason` 이 `분석 실패`)으로
  바꾼 사본으로도 확인한다.
- 기대: 두 경우 모두 화면의 Gemini 배지가 오늘 자 판정을 유지하고 툴팁에 `[legacy 판정]`
  표식이 없다. 두 번째 경우에는 CSV 가 만든 판정이 그대로 보인다. code-review 가 찾은
  회귀이며, 보강 조건을 「비어 있을 때만」 으로 되돌려 막았다.
- 필수 여부(required): 예
- 실제: 첫 경우에서 legacy 사본의 gemini 를 `SELL` 로 바꾸어 두었는데도 화면의 Gemini
  배지가 오늘 자 `HOLD` 를 유지했고 툴팁에 `[legacy 판정]` 표식이 없었다. 두 번째
  경우에서는 오늘 JSON 의 gemini 를 실패 기록으로 바꾸고 CSV 의 `ai_action` 에 `BUY` 와
  「오늘 CSV 가 담은 사유입니다.」 를 채운 자료로 확인했다. API 응답과 화면 배지가 모두
  그 CSV 판정을 유지했고 legacy 의 `SELL` 로 밀려나지 않았다. 콘솔 오류 0 건.
- 결과: 통과
