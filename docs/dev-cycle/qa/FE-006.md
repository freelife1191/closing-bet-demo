모든 agent-browser 명령에 `--session adguard-cft-extension` 을 붙입니다. 이 브라우저에는
다른 작업의 탭(`localhost:3000` 의 CaseLink.ai)이 함께 열려 있습니다. **그 탭을 닫지
않습니다.** 활성 탭이 그쪽으로 넘어가는 일이 잦으므로 `eval` 의 반환값에 항상
`location.href` 를 넣어 `3500` 인지 확인하고, 아니면 `tab t1` 로 되돌린 뒤 다시 읽습니다.

이 세션의 `screenshot` 은 CDP `Page.captureScreenshot` 이 응답하지 않아 120초 타임아웃이
납니다. 증거는 DOM 실측값으로 남깁니다.

## 시나리오

### S-1. 저장된 API 키가 값이 아니라 안내 문구로 표시된다 (회귀)
- 조작: 설정 모달을 열고 「API & 기능」 탭을 누른다. `input[type=password]` 두 개의
  `value` 와 `placeholder` 를 읽는다.
- 기대: 두 칸 모두 `value` 가 빈 문자열이고 `placeholder` 가
  `저장되어 있습니다. 바꾸려면 새 값을 입력하세요` 다. 두 칸이 완전히 같은 문구를 쓴다.
  한쪽만 `sk-...` 나 `pplx-...` 로 남아 있으면 실패다.

### S-2. 마스킹 문자열이 화면 어디에도 나타나지 않는다 (회귀)
- 조작: 「API & 기능」 탭이 열린 상태에서 모달 요소의 `innerText` 를 읽고, 별표가 둘
  이상 이어진 구간과 `sk-` 또는 `pplx-` 로 시작하는 문자열을 찾는다.
- 기대: 별표가 이어진 구간 0건, `sk-`/`pplx-` 로 시작하는 문자열 0건. `type="password"`
  의 placeholder 는 점 처리되지 않고 평문으로 그려지므로 마스킹 값을 자리 표시자로 쓰면
  키 앞뒤 네 글자가 보이게 되는데, 그 상태가 아니어야 한다.
- 결과:

### S-3. 예전 버전이 브라우저에 남긴 API 키가 설정 화면을 열 때 지워진다 (회귀)
- 조작: 모달이 닫힌 상태에서 `localStorage` 에 네 키를 심는다.
  `OPENAI_API_KEY`, `PERPLEXITY_API_KEY`, `X-Gemini-Key`, `GOOGLE_API_KEY` 이며 값은
  아무 문자열이면 된다. 그다음 설정 모달을 연다.
- 기대: 네 키가 모두 `null` 이 된다. 모달을 열고 「API & 기능」 탭까지 오간 뒤에도
  `localStorage` 에 이름에 `KEY`·`TOKEN`·`SECRET` 이 들어간 항목이 하나도 생기지 않는다.
  실측 시점에 남아 있던 항목은 `nextauth.message`, `browser_session_id`, `watchlist`
  셋뿐이었다.
- 결과:

### S-4. 탭을 오갔다 돌아와도 두 입력 칸의 상태가 같다 (인접)
- 조작: 「API & 기능」 탭에서 두 칸의 `value` 와 `placeholder` 를 읽는다. 「일반」 탭으로
  옮겼다가 다시 「API & 기능」 탭으로 돌아와 같은 값을 읽는다.
- 기대: 두 번 읽은 값이 완전히 같다. 즉 `value` 는 두 번 다 빈 문자열이고 `placeholder`
  는 두 번 다 `저장되어 있습니다. 바꾸려면 새 값을 입력하세요` 다.
- 결과:

### S-5. Gemini 절은 입력 칸 없이 안내만 보여 준다 (인접)
