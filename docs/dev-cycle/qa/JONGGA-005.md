### S-3. 종목코드가 화면과 외부 링크에서 원본 그대로다 (회귀)

- 기대: 카드 제목 아래 코드가 `0007C0` 이다. 링크는
  `https://m.stock.naver.com/domestic/stock/0007C0/main` 과

- 결과: 통과. 코드가 `0007C0` 이고 두 링크도 `0007C0` 이다. 문서 전체 HTML 에서
