## 시나리오

### S-1. 카드 지표 세 번째 자리가 「종가」다 (회귀)

- 조작: 화면을 연다. 태웅 카드 왼쪽 지표 네 칸 가운데 세 번째 칸의 라벨과 값을 읽는다.
  그다음 화면 전체 텍스트에서 「현재가」를 찾는다.
- 기대: 라벨은 `종가`, 값은 `₩37,250` 이다. 메리츠금융지주 카드는 `종가` / `₩129,800`
  이다. **화면 전체에서 「현재가」가 0회다.** 「종가」 라벨 뒤에 「가장 최근 거래일의
  종가입니다」로 시작하는 툴팁이 붙는다.
- 결과: (미정)

### S-2. 매수가 옆에 신호가 나온 거래일이 붙는다 (회귀)

- 조작: 태웅 카드 오른쪽 「전략 포인트」의 첫 줄 「매수가」에 적힌 값과 그 뒤 괄호를 읽는다.
  메리츠금융지주 카드에서도 같은 자리를 읽는다.
- 기대: 태웅은 `₩37,200(2026-09-02 종가)`, 메리츠금융지주는 `₩129,800(2026-09-02 종가)`
  이다. 괄호 안 날짜는 화면 상단 안내가 말하는 「최신 저장 데이터는 2026-09-02입니다」와
  같은 날짜다.
- 결과: (미정)

### S-3. 목표가와 손절가 옆에 매수가 대비 비율이 붙는다 (회귀)

- 조작: 같은 「전략 포인트」의 둘째 줄과 셋째 줄을 읽는다.
- 기대: 태웅은 목표가 `₩39,060(매수가 +5.0%)`, 손절가 `₩36,084(매수가 -3.0%)` 이고,
  메리츠금융지주는 `₩136,290(매수가 +5.0%)`, `₩125,906(매수가 -3.0%)` 이다.
  네 값 모두 매수가에 그 비율을 곱한 값과 원 단위까지 일치한다
  (37,200×1.05=39,060 / 37,200×0.97=36,084 / 129,800×1.05=136,290 / 129,800×0.97=125,906).

### S-4. 상세 모달의 두 범위 라벨이 「실시간」이다 (회귀)

- 조작: 태웅 카드의 「상세 분석 보기」를 누른다. 「시세 정보」 절의 「1일 범위」와
  「52주 범위」 막대 오른쪽 라벨을 읽는다. 이어서 「투자 지표」 절의 시가총액 툴팁을 읽는다.
  Escape 로 닫는다.
- 기대: 두 라벨 모두 `실시간` 이고 「현재」가 아니다. 시가총액 툴팁은
  `발행주식수 × 주가. 기업의 시장가치를 나타냅니다.` 이며 「현재가」라는 말이 없다.
  모달 전체 텍스트에서 「현재가」가 0회다. Escape 로 모달이 닫힌다.
- 결과: (미정)

### S-5. 모달의 「전일종가 (Prev)」가 카드의 「종가」와 같다 (회귀)

- 조작: 태웅 카드의 「종가」 값을 적어 둔 뒤 「상세 분석 보기」를 열어 「전일종가 (Prev)」와
  「1일 범위」의 실시간 값을 읽는다.
- 기대: 「전일종가 (Prev)」는 `37,250` 으로 카드의 「종가」 `₩37,250` 과 같다.
  「1일 범위」의 실시간 값은 그와 **다르다**(측정 시점 ₩38,350, 장중이라 변동한다).
  같은 값을 두 이름으로 부르지 않고, 다른 값을 두 이름으로 각각 부르는 상태다.
- 결과: (미정)

### S-6. 필터 네 개를 걸어도 카드 안의 값이 변하지 않는다 (인접)

- 조작: 거래대금 필터를 `1조 이상` 으로, 되돌린 뒤 상승률 필터를 `10% 이상 (Strong)` 으로,
  되돌린 뒤 등급 필터를 `S급 이상` 으로, 되돌린 뒤 총점 필터를 `10점 이상` 으로 바꾸고
  각각에서 카드 목록과 값을 읽는다. 마지막에 모두 `전체` 로 되돌린다.
- 기대: 목록만 달라지고 카드 안의 값은 그대로다. 거래대금 `1조 이상` 은 카드 0장,
  상승률 `10% 이상` 은 태웅 1장, 등급 `S급 이상` 은 0장, 총점 `10점 이상` 은 2장이다.
  카드가 남는 경우 라벨은 언제나 `종가` 이고 값은 `₩37,250` · `₩129,800` 이다.
  모두 되돌리면 처음 상태로 복귀한다.
- 결과: (미정)

### S-7. 날짜를 바꾸면 라벨과 기준 날짜와 비율이 새 자료를 따른다 (인접)

    괄호 `(2026-02-11 종가)` 4개, 비율 표기 `(매수가 +5.0%)` 4개와 `(매수가 -3.0%)` 4개.
