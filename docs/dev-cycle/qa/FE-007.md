### S-3. 수익 차트의 기간과 이동평균선 선택이 탭을 오간 뒤에도 남는다 (회귀)

  「3일」을 체크한다. 「자산 개요」 탭으로 갔다가 다시 「수익 차트」로 돌아온다.
- 기대: 기간은 「1개월」이 선택된 채(분홍 배경)이고 이동평균선은 「3일」과 「10일」 둘 다
  체크되어 있다. 차트도 다시 그려진다. 기본값인 「1년」과 「10일」만으로 되돌아가지 않는다.
- 근거: 차트를 별도 컴포넌트로 뗀 뒤 탭을 벗어나면 언마운트되어 선택이 초기화되었다.
  React 19.2 의 `<Activity>` 로 감싸 상태를 지키면서 effect 는 정리하도록 고쳤다.
- 결과: 통과. 기본값 「1년」·「10일」에서 「1개월」·「3일」+「10일」로 바꾼 뒤 탭을 왕복해도 같은 값이 남았고 canvas 도 다시 그려졌다.

### S-4. 다른 탭에 있을 때 차트 요소가 겹쳐 보이지 않는다 (회귀)

- 조작: 모의투자 모달의 「자산 개요」 탭에서 화면을 본다. 기간 버튼(1개월·3개월·6개월·
  1년·전체)과 이동평균선 체크박스가 보이는지 확인한다.
- 기대: 하나도 보이지 않는다. `Activity` 가 숨긴 차트의 최상위 `div` 에 인라인
  `display: none` 이 걸려 있고, 그 안의 요소는 `offsetParent` 가 `null` 이며 접근성
  트리에도 나오지 않는다.
- 근거: `<Activity mode="hidden">` 은 자식을 언마운트하지 않고 DOM 에 남긴다. 숨김이
  실제로 걸리지 않으면 다른 탭에 차트의 조작 요소가 겹쳐 보이게 된다.
- 결과: 통과. 차트 루트의 인라인 `display` 가 `none` 이고 「3개월」 버튼의 `offsetParent` 는 `null`, 사각형 너비는 0 이다. 접근성 트리에서 기간 버튼이 0건으로 잡혔다.

### S-6. 랜딩의 탭 셋이 각자의 패널로 정확히 갈린다 (인접)

### S-7. 보유 종목의 매수·매도 버튼이 그 종목의 주문 대화상자를 연다 (인접)

  않는다.**
- 기대: 「매수」에서는 「모의 투자 매수」가, 「매도」에서는 「모의 투자 매도」가 열린다.
  행의 다른 곳을 누르면 「삼성증권 거래 내역」이 열린다. 셋이 서로 섞이지 않는다.
- 근거: `/qa-only` 리포트가 ISSUE-001 로 「매수를 눌러도 거래 내역이 열린다」를 High 로

### S-8. 충전 팝오버의 가산 버튼이 금액을 정확히 더한다 (인접)

- 조작: 모의투자 모달 헤더의 예수금 옆 「+」를 눌러 충전 팝오버를 연다. 입력 칸의 초기값을
  읽고 「+1억」을 두 번 누른다. **「충전하기」는 누르지 않는다.**
- 기대: 초기값 `10,000,000` 에서 `110,000,000`, 다시 `210,000,000` 으로 정확히 1억씩
  늘어난다. 「+100만」과 「+1천만」 버튼도 함께 있다.
- 근거: 입금과 계정 초기화를 `PaperTradingAccountActions.tsx` 로 떼어내면서 금액만 다른
  세 벌의 버튼 코드를 배열 하나로 합쳤다. 합치는 과정에서 금액이 어긋나지 않았는지 본다.
- 결과: 통과. `10000000` → `110,000,000` → `210,000,000` 으로 1억씩 정확히 더해졌다. 가산 버튼 셋이 모두 있고 「충전하기」는 누르지 않았다.

### S-9. 모달을 두 번째로 열면 스피너 없이 옛 값이 먼저 보인다 (인접)

- 조작: 모의투자 모달을 열어 「총 평가 자산」과 「예수금」을 읽는다. 닫았다가 곧바로 다시
