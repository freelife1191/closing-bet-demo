기존 38fab47에서 tmp_path 전환과 연결/임시 파일 정리를 마쳤고 UltraQA 5/5를 통과했다. 그 구현 파일은 이후 변경 여부를 git 비교로 검토한다. 2026-09-21 격리 전체 pytest에서도 원본 data 쓰기를 OS 정책으로 차단했다. 과거 27396개는 2026-09-09 관측값으로 현재 값이 아니다.
