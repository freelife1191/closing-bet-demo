## 변경

모바일 상세를 차트·이동평균선 버튼·정보 막대·AI 패널의 세로 흐름으로 배치했다. 1/3/6개월·1년 버튼을 기존 API에 연결하고 과거 기준일을 유지한다. 응답에서 관측한 7일 초과 날짜 간격을 표시하며 실제 휴장·거래정지·수집 누락 원인을 단정하지 않는다. 원본 CSV 읽기 전용 집계에서 2,883종목 중 1,992종목에 긴 간격이 있었고 1,871종목이 동일한55일 간격을 공유했다.

제품 파일은 `frontend/src/app/dashboard/kr/vcp/{page.tsx,StockChart.tsx,chartUtils.ts}` 세 개다. 테스트는 같은 폴더의 기존 두 파일을 확장했다. 의존성·백엔드·원본 자료는 변경하지 않았다.

## 리뷰

ponytail 검토에서 테스트의 4단계 DOM 부모 탐색을 이름 있는 닫기 버튼으로 줄였다. 독립 code review가 실패와 빈자료구분 및 날짜안내UI검사를 요구해 반영했다. code-review-v3 APPROVE, architecture-review-v3 CLEAR. 초기 WATCH와 REQUEST CHANGES 원문도 보존했다. 새 역할 호출의 thread limit 때문에 기존 native agents가 code-reviewer/architect 지침을 읽어 대체 수행했으며 전용역할호출 성공으로 취급하지 않는다. LSP 실행파일이 없어 실제 typecheck/lint와 읽기검토를 사용했다.

## 정리·한계

임시Next·합성API·차단proxy를 소유PID/PGID/cwd/명령으로 검증해 종료했다. 전용browsernamespace/profile과가짜env/cookies를제거했다. 원본package.json SHA를보존했다. native OMX scope가없어 state write/read/clear는사용하지않았다.
