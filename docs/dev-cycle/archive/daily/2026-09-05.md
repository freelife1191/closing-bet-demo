  `load_json_payload_from_sqlite` 가 `json.loads` 로 복원하는데 JSON 은 `Infinity` 를

  `INSERT ... ON CONFLICT DO UPDATE` 를 쓰기 때문이며, 그래서 무한 캐시 미스가 생기지 않는다.
