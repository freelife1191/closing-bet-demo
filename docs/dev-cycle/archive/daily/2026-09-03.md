  에서 「신호가 나온 거래일까지 5일간」으로 바꿨다. 항목이 「각각」이라고 적었으므로 카드
  한쪽만 고치면 절반이다. 카드 라벨 자체는 그대로 두었다. 지표 여섯 개가 좁은 칸에 나란히
  놓인 자리라 라벨이 길어지면 줄바꿈이 생기고, 같은 카드의 「상승률」과 「종가」 툴팁이
  이미 신호일 기준임을 밝히고 있어 맥락도 일관된다.

  카드의 조 단위 표기가 포맷 통합으로 「1조 2400억」에서 「1.2조」로 바뀌었다. 시가총액과
  재무 3종의 표기가 함께 달라지므로 좁은 칸에서 길어지는 것을 견딜 수 있는지 따로 판단해야
  해서 `[JONGGA-026]` 으로 이월했다. `[VCP-017]` 도 같은 이유로 이월했다.

  1단계 `/qa-only` 가 날짜 select 에 빈 문자열을 넣어 화면을 통째로 망가뜨린 관찰이
  있었으나 결함으로 올리지 않았다. 옵션 13개에 빈 값이 없어 사용자가 도달할 수 없고 DOM 을
  직접 조작해야만 만들 수 있는 상태다.
