# 빌드 검증

기본 `npm test` / `npx vitest run`은 단위 테스트와 파일 스모크 검사만 실행합니다.
`npm run test:build`는 실제 빌드 1회, 필수 라우트 확인, TypeScript 검사를 순서대로 실행합니다.
전체 검증에서는 두 명령을 모두 실행하세요. 빌드 검증을 생략한 단위 테스트 통과는 빌드 성공을 뜻하지 않습니다.

빌드·개발 서버·다른 빌드 검증끼리는 같은 checkout의 `.next`를 공유하므로 동시에 실행하지 마세요.
병렬 작업에는 독립 checkout을 사용하세요. 테스트는 애플리케이션이 쓰는 환경 설정을 읽으므로
시크릿과 실제 데이터가 없는 격리 checkout에서 실행합니다.
